# SwissFlora — Website

Landing page for the **SwissFlora** iPhone app — the most comprehensive Swiss alpine flower reference, available on the [App Store](https://apps.apple.com/app/id6775167690).

## What's in this repo

| File | Description |
|------|-------------|
| `index.html` | Single-page landing page (DE / FR / EN) |
| `style.css` | All styles for the landing page |
| `screen1–4.png` | App screenshots used in the page |

## Features highlighted on the page

- **AI plant recognition** — photograph a plant and identify it instantly using the InfoFlora database
- **Name search** — search by German, French, or Latin species names
- **170 botanical illustrations** — scientific drawings available fully offline
- **2 500+ wild flower and fern species** — complete Swiss flora coverage
- **Offline use** — full taxonomy database works without mobile signal

## Tech

Plain HTML + CSS, no build step required. Open `index.html` directly in a browser or serve from any static host.
